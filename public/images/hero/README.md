# Photographies du hero

Déposer ici uniquement des photographies réelles et validées du salon.

Préparer idéalement :

- une version paysage desktop autour de 2400 × 1600 px ;
- une version portrait mobile autour de 1080 × 1440 px lorsque le recadrage diffère ;
- des fichiers WebP ou AVIF correctement compressés ;
- un texte alternatif court si la photographie transmet une information.

Renseigner les chemins, dimensions et points focaux dans `.env.local`. Les variables utilisées sont décrites dans le README principal.
